# Helminth Tunnel Speed Fix
Fixes certain characters that don't walk with footsteps such as CHEF and Void Fiend from being able to get speedups in the Helminth Hatchery worm husks, because they don't have footsteps.

Gearbox, you can fix this by checking if they're on the ground the exact same way you check for lava. It doesn't need to be different with footsteps!
